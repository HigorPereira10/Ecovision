# docs/tcc

Espelho local dos capítulos da escrita acadêmica do TCC (o documento
"oficial" fica na pasta compartilhada do Google Drive do grupo (ver
link no README raiz). Útil para versionar rascunhos técnicos que citam
diretamente arquivos deste repositório (ex.: trechos de código,
resultados de avaliação do modelo).

Pontos do Tech Stack Blueprint v3.0 que precisam virar texto de TCC:

- Justificativa da estratégia "Frankenstein Cirúrgico" (ml/README.md)
  como argumento de originalidade acadêmica.
- Explicação **proativa** do risco estatístico do split 70/15/15 e do
  uso de `class_weight` / F1 weighted (ver `ml/README.md` e Blueprint
  Seção 3), preparar antes da banca, não reativamente.
- Documentação do gap entre F1 sintético e F1 real (imagens de campo).
- Correção das contradições textuais entre o TC1 e este Blueprint
  (câmera V2→V3, contagem de classes 10 não 11, hospedagem, autenticação)
